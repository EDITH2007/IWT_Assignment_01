How this JavaScript Visitor Counter Works:
  • Automatic Count on Site Load: The hit counter logic runs inside header.html whenever the site loads.
  • Page Refresh: Refreshing the page (F5 / Ctrl+R) does NOT increase the count because sessionStorage["counted"] persists during the tab session.
  • New Sessions: Opening a new browser tab, opening an incognito/private window, or closing and reopening the browser starts a new session and increments the count by 1.
  • sessionStorage vs localStorage: sessionStorage (like PHP session variables) lasts until the tab closes. localStorage (like count.txt) persists permanently across browser restarts.
  • Client-Side Limitation: Because JavaScript executes in your browser, this count is per-browser. A shared, site-wide counter across all internet users requires a backend web server.
