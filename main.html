Interactive Client-Side Image Map

Welcome to the main content area! Below is a Client-Side Image Map demo. Unlike standard image links that link the entire picture to one web page, an image map divides a single image into multiple clickable hotspot regions (coordinates).

🟢 Left Shape: Circle Hotspot → Links to home.html
🟧 Right Shape: Rectangle Hotspot → Links to contact.html

Hover your mouse cursor over the circle or rectangle in the graphic above to test the clickable hotspots!
